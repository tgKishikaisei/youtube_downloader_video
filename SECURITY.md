# Безопасность

## Как сообщить об уязвимости

Не открывайте публичный issue. Нажмите «Report a vulnerability» на вкладке **Security** или напишите мне в Telegram: [@BehruzAvezmatov](https://t.me/BehruzAvezmatov).

## Что сделано

- Ссылку разбирает `urllib.parse`: принимается только http(s) с хостами из белого списка (youtube.com, m.youtube.com, music.youtube.com, youtu.be). Бот вызывает yt-dlp через Python API, а не командную строку, поэтому текст пользователя не станет опцией.
- Формат берётся только из кнопок, которые бот сам предложил; строка формата из callback в yt-dlp не передаётся.
- Лимиты на размер, длительность и число одновременных загрузок защищают сервер от перегрузки одним пользователем.
- Файлы каждой загрузки лежат в отдельной временной папке и удаляются после отправки, чужие файлы не пересекаются.
- Название и автор ролика экранируются в HTML; текст исключений пользователь не видит.
- Токен и путь к cookies берутся из `.env`, оба файла в `.gitignore`.

GitHub Actions на каждый push запускает тесты, `pip-audit` и `gitleaks` по всей истории.
